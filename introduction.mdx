**IQX Studio is the browser-based AI development workspace at [iqx.dev](https://iqx.dev).** Describe an application, work with the agent on its source code, inspect it in a live preview, and publish when it is ready.

A project can include a web app, an Expo / React Native mobile app, a backend and data services. Work with code and the visual canvas in the same workspace. The agent can help create files, run commands, investigate errors and make follow-up changes.

<Note>
IQX is in Beta. Features can depend on your plan, project configuration and rollout. Review and test generated code before using it in production.
</Note>

## How the pieces fit together

| Part | Purpose | Guide |
| --- | --- | --- |
| AI agent | Reading and changing code, running tools and checking results | [Prompting](/prompting) |
| Web app | Browser interfaces, routes and user workflows | [Web apps](/web-apps) |
| Mobile app | Expo / React Native screens and device workflows | [Mobile apps](/mobile-apps) |
| Canvas | Organizing previews, design elements and service relationships | [Canvas](/canvas) |
| Backend and data | Server logic, PostgreSQL, Redis and object storage | [Services](/services) |
| Production | Publishing a version at a public URL | [Deployments](/deployments) |

Preview and production are separate stages. Editing code in Studio does not mean a production release has succeeded. Check the publish status and test the public URL after each release.

## Build, inspect, improve

Start with one user and one workflow. Describe what the user should be able to do, what data is needed and what a successful result looks like. Let the agent work, then test the result yourself. Ask for the next focused change after the first workflow works.

You can connect an existing repository, configure supported external services and collaborate with other people. These connections have their own permissions and setup requirements; a provider logo alone does not grant access to an account.

## Understand the cost

Free includes **50 credits per month** for public projects. Paid plans add credits and capabilities. Agent work uses credits, some generated media has separate credit charges, and production compute is billed by usage.
