## How credits are calculated

An agent run can contain several billable iterations. One prompt is not necessarily one iteration: the agent may inspect files, make changes and respond to the result over several steps.

For a run using one rate, the basic calculation is:

```text
Agent credits = effective model rate × billable iterations
```

For example, four billable iterations at 1.5 credits cost 6 credits before any separately charged tools. This is an illustration, not a promised cost per prompt.

<Note>
Image generation, image editing and 3D generation can carry additional credit charges. Production hosting and external provider bills are separate from agent credits. See [Usage and billing](/usage-and-billing).
</Note>

Low balances can temporarily restrict premium models even on a paid plan. Check the message in Studio and the remaining balance before changing subscriptions to resolve a model-access issue.

## Reasoning effort

The effort selector controls the reasoning setting sent to the selected model. Supported choices vary by model and can include Low, Medium, High, XHigh and Max. Use the choices actually shown in Studio.

For a small copy or layout change, keep the request narrow. For a difficult bug, provide the reproduction steps and relevant context before increasing effort. More effort does not guarantee a correct answer or a lower total run cost.

## Keep a run focused

Describe the expected outcome, identify the affected page or file, and say how to verify success. Inspect the first result before asking for several additional features. If a run heads in the wrong direction, stop it, review changes and clarify the request.

Opening files and inspecting a preview are different from asking the agent to perform work. Check your balance and usage history when investigating a charge, and compare the effective rate with the model selected for that run.
